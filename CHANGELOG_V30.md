# V3.0 — Courriers administratifs

- Guide par type de courrier : justificatif, décision, trop-perçu, refus, suspension, convocation, inconnu.
- Question sur échéance et réponse attendue, sans collecte de document.
- Alerte prioritaire pour les cas sensibles ; rappel de vérifier les recours et délais sur la notification.
- 4 langues ; 65 cas de test ; intégré au parcours conseiller « courrier ».
- Aucune interprétation juridique automatisée ni détermination de délai de recours.
