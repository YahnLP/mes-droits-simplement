# Confidentialité et limites

Les réponses du questionnaire restent en mémoire dans le navigateur : elles ne sont ni envoyées à GitHub ni sauvegardées par l’application. La page charge seulement les fichiers statiques du site. Les liens vers les organismes sont facultatifs et ouvrent des sites tiers. GitHub Pages reçoit les informations techniques normales d’une visite web, dont potentiellement l’adresse IP.

Le projet ne réalise ni diagnostic médical ni conseil juridique individualisé. Les résultats sont des pistes et ne constituent pas une décision d’éligibilité. Les sources peuvent changer ; leur surveillance ne valide pas les conditions des aides. Ne jamais entrer un numéro de sécurité sociale, un titre de séjour, un nom ou un dossier médical.

La méthode FALC exige des tests et une validation par des personnes concernées. Les traductions doivent également être relues.
